### Currently building
**Strata** — a desktop ecosystem for digitizing and managing borewell and materials data, born out of my father's drilling business.

- **[StrataField](https://github.com/Mehulsri07/StrataField)** — the core app. Electron/React/TypeScript/SQLite. Includes a custom Excel ingestion parser with anomaly detection, unit conversion, and multi-borewell sheet handling, plus a two-family lithology taxonomy (CLAY/SAND) for materials classification.
- **[StrataDesk](https://github.com/Mehulsri07/StrataDesk)** — the web predecessor. Refactored from a vanilla JS prototype into a full-stack React app: JWT auth, secured API endpoints, unified cross-section engine, CI/CD pipeline with EC2 deploy.
- Next up: **StrataVision**, a 3D lithological visualization layer — blocked on StrataField digitizing enough records to feed it.

**[LoadLab](https://github.com/Mehulsri07/LoadLab)** — a Dockerized system built to fail on purpose. Nginx + Node/Express backend with intentionally expensive endpoints, Prometheus/Grafana for metrics, k6 for load generation at three intensities. Deployable to EC2 for realistic remote load testing.
